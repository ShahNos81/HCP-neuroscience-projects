# HCP Neuroscience Projects

A step-by-step learning and research journey using the Human Connectome Project (HCP) dataset.

## 🎯 Goals

This repository documents my journey from learning the fundamentals of neuroimaging to conducting advanced neuroscience research using HCP data.

The main goals are:

- Learn modern neuroimaging analysis
- Understand the structure of HCP datasets
- Work with NIfTI, GIfTI, and CIFTI files
- Learn HCP Workbench
- Perform resting-state fMRI analysis
- Perform task-fMRI analysis
- Study functional connectivity
- Explore brain parcellation
- Conduct neuroscience research projects
